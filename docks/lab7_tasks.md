### Вариант 1
Пусть имеется следующий класс _MyStack_.  
Нужно добавить метод поиска объектов по значению, используя метод _equals()_.  
Протестировать стек на данных класса, уже имеющегося в java (например, числа, символы
или строки) и собственного класса, в котором переопределён метод _equals()_.
Добавить в класс обработку следующих исключений:
- удаление данных из пустого стека,
- добавление в стек уже существующего элемента (считаем, что каждый элемент должен
  встречаться в стеке не более одного раза).
```java
import java.util.ArrayList;

public class MyStack {
private ArrayList<Object> list = new ArrayList<>();

public boolean isEmpty() {
  return list.isEmpty();
  }

  public int getSize() {
  return list.size();
  }

  public Object peek() {
  return list.get(getSize() - 1);
  }

  public Object pop() {
  Object o = list.get(getSize() - 1);
  list.remove(getSize() - 1);
  return o;
  }

  public void push(Object o) {
  list.add(o);
  }

  @Override /** Переопределяет метод toString класса Object */
public String toString() {
  return "стек: " + list.toString();
  }
}
```
