## Задания по теме 3. Часть 2
### Задание 1
Представьте, что вы разрабатываете библиотеку фильмов и сериалов. Ваша
задача создать иерархию классов для описания фильмов и сериалов, а также
продемонстрировать взаимодействие объектов этих классов друг с другом и
понимание особенностей наследования, переопределения и перегрузки
методов, динамического связывания и обработки коллекции
фильмов/сериалов с помощью _ArrayList_.

Подробности задания:
1. Класс _Movie_
- Абстрактный суперкласс, представляющий фильм.
- Элементы-данные: название фильма (_title_), продолжительность (_duration_),
  рейтинг (_rating_).
- Методы:
  - Конструктор с параметрами для инициализации полей.
  - Метод _toString()_, возвращающий строку вида "Название: ХХХ,
    Продолжительность: 140 , Рейтинг: 2.5".
  - Переопределенный метод _equals(Object obj)_ для проверки равенства двух
    фильмов по названию и продолжительности.
2. Подкласс _FeatureFilm_ (художественный фильм)
- Наследуется от класса _Movie_.
- Дополнительный атрибут: жанр (genre).
- Переопределённый метод _toString()_, дополнительно отображающий жанр.
- Использование конструктора суперкласса через ключевое слово super.
3. Подкласс Documentary (документальный фильм)
- Наследуется от класса _Movie_.
- Дополнительный атрибут: режиссёр (_director_).
- Переопределённый метод _toString()_, дополнительно отображающий
  режиссёра.
- Метод, показывающий уникальность документального кино, например,
  уникальный способ съемки (_uniqueShots()_).
4. Метод _main()_
- Создайте коллекцию _ArrayList<Movie>_, содержащую экземпляры обоих
  подклассов (_FeatureFilm_ и _Documentary_).
- Используйте цикл _for-each_ для обхода списка и вывода подробностей
  каждого фильма.
- Продемонстрируйте использование оператора _instanceof_ для проверки
  принадлежности конкретного элемента коллекции определённому классу
  (является ли фильм художественным или документальным).
- Демонстрируйте работу полиморфизма путём вызова метода _toString()_ на
  объектах разного типа.
  
### Задание 2
  Разработайте приложение для управления автомобильным парком
  транспортных средств, состоящим из легковых автомобилей и грузовиков.
  Проект должен включать создание классов, демонстрацию наследования,
  полиморфизма, переопределения методов, работы с оператором instanceof
  и структурированной обработкой данных с помощью коллекции ArrayList.
  Основные условия задания:
1. Абстрактный класс _Vehicle_ (транспортное средство):
- Общие поля: марка автомобиля (brand), максимальная скорость
  (_maxSpeed_), пробег (_mileage_), мощность двигателя (_enginePower_).
- Общий метод: абстрактный метод _calculateFuelConsumption()_,
  рассчитывающий расход топлива в зависимости от мощности двигателя и
  пробега.
2. Подкласс _Car_ (легковой автомобиль):
- Поля: количество дверей (_numberOfDoors_), объём багажника
  (_trunkVolume_).
- Переопределённые методы: расчёт расхода топлива учитывает
  вместимость багажника и число дверей.
3. Подкласс _Truck_ (грузовик):
- Поля: грузоподъёмность (_cargoCapacity_), категория водительских прав
  (_drivingCategory_).
- Переопределённые методы: расход топлива зависит от груза и
  категории водителя.

4. Метод класса _Object_
   Переопределить метод _equals()_ для адекватного сравнения объектов.
   Переопределить метод _toString()_ для строкового представления объектов
   каждого типа.
4. Метод _main()_
   - Формируются объекты автомобилей и грузовиков.
   - Они помещаются в единый список _ArrayList_.
   - Выполняется обработка каждого элемента коллекции (в цикле _foreach_): 
     вывод информации об автомобиле и расчёт потребления
   топлива.
   - Определяется принадлежность конкретных объектов различным
   классам с помощью оператора _instanceof_.
   - Рассчитывается общий пробег всего автопарка.
