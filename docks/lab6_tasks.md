### Задание 1
Определите класс _Triangle_ – треугольник с тремя сторонами.  
Создайте класс _IllegalTriangleException_.  
Реализуйте конструктор класса _Triangle_, чтобы выбросить исключение типа
_IllegalTriangleException_, если треугольник создан со сторонами,
нарушающими неравенство треугольника
```Java
/** Создает треугольник с указанными сторонами */
public Triangle(double side1, double side2, double side3)
        throws IllegalTriangleException {
// Реализуйте его
}
```
В качестве демонстрации работы исключения cоздайте _массив
или ArrayList_, в который _циклически_
последовательно добавляются _10 треугольников_ со _случайными_ сторонами.  
Если создаётся неправильный треугольник – выбрасывается исключение и создаётся новый треугольник.  
Программа должна _выводить_ на консоль сообщение о 
«неправильном» треугольнике и подсчитывать их общее количество.

длины третьей стороны(неравенство треугольника).
~~~

### Задание 2
Реализуйте простую банковскую систему выдачи кредитов с
использованием собственной системы исключений. 
Пользовательские запросы будут содержать сумму кредита и срок погашения. Вам потребуется
обработать ряд потенциальных ошибок и ситуаций, возникающих при
выдаче займа.
1. Напишите класс _LoanRequest_, представляющий заявку на кредит. Заявка
   включает две характеристики: сумма кредита и срок возврата (в месяцах).
2. Создайте два класса исключений:
   - _InvalidAmountException_: ошибка при неверной сумме кредита
    (например, сумма равна нулю или сумма меньше возможного минимума).
   - _InvalidTermException_: ошибка при некорректном сроке кредитования
    (например, срок равен нулю или меньше минимального срока,
    установленного банком).
3. Напишите класс банка _Bank_, содержащий метод _approveLoan()_ и поле
   _ArrayList< LoanRequest> loans_. Метод _approveLoan()_ принимает объект
   заявки и либо одобряет займ, добавляя его в коллекцию _loans_, либо
   генерирует соответствующее исключение.
4. Продемонстрируйте функциональность вашей банковской системы,
   реализовав метод _main()_. Реализуйте следующий сценарий: система
   циклически генерирует 25 кредитов со случайными параметрами суммы и
   срока. Если заявка на кредит корректна – она добавляется в список кредитов
   банка, если нет – выброшенное исключение обрабатывается. Программа
   ведёт подсчёт числа корректных и некорректных заявок.
